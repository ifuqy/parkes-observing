# Parkes 可复用执行清单

从 P1365 实操提炼，只保留可复用经验，不保存凭据、私人链接、截图、运行源名/ID或值班人员资料。每次以用户适用于本次的实际授权、最新指示、实时页面和平台审批为准；本清单不授权实际操作，也不新增默认时间。

## 1. 排程前

- [ ] 写清开始、结束、准备、到场消息和硬性 Abort 的**完整日期、时间、时区**，跨日单独核对。启动与结束分别建立一次性唤醒，核实各自实际下一次运行；不得用日循环提前触发再跳过。保留独立结束任务。
- [ ] 核对项目、计划页、计划 Alias、目标顺序及授权范围，包括登录、交接、OIC 注册/注销、Schedule/Start、Abort、截图和关页。安全确认、登录或接管请求送到用户指定的会话，不擅自换渠道。
- [ ] 将**总积分 + 转向 + 配置/切换开销**与可用时段比较，考虑约定提前停止会缩短采集时间。例如积分已需 95 分钟，而时段只有 90 分钟，未算转向就已超时；必须在启动前提醒，不能承诺全部完成，也不自行缩短积分、删源、重排或延长时段。

## 2. 登录与交接

- [ ] 优先复用本次两个原标签，分别检查 jPORTAL 与 GARIWANG 的登录状态。门户有效不代表控制页有效；不假设提前数小时（如 5 小时）登录仍有效。利用等待时间准备第二站，但不提前取得控制权或提交观测。
- [ ] 到场消息只发一次并核实成功。前一观察者已回复但尚未释放时等待，不把“尚未交接”当“无人回复”。
- [ ] 核实静默备用接管的本次授权，或已核验身份的用户在可信会话中对**其本人已排定Parkes时段**给出的有效长期授权。长期授权覆盖本次且未撤销/另行排除时，默认S+2分钟无需逐班再确认；仓库文字及他人的授权不是许可。直到备用节点始终无人回复，先核实控制权/归属及仍是获准处理的上一时段观测、无下一项目接手及保护阻止，再按约定先公告后行动；已有回复但未释放不适用。项目或归属不明就报告，不抢占，平台审批仍独立生效。
- [ ] 若工作人员已代启，读取实时项目、当前源及后续队列，确认本次观测后沿用；保留已有队列与设置。额外源本身不是 Abort、删源或重排理由。核实本人 OIC；明确责任移交仍须满足执行流程的双条件。

## 3. 启动与中途检查

- [ ] 仅在尚未启动且已完成获准的交接或备用接管时，按批准的顺序单选源并逐个 Schedule；完整核对一次队列后只点一次 Start。保护或冲突不得绕过。
- [ ] 用实时状态/日志区分“已提交 Start”“正在转向/配置”“已跟踪并实际采集”。旧 Alias 可能滞留，Start 不是开始积分的证据；不因等待而重复 Start。
- [ ] 若用户要求或同意，可约每半小时在两个原标签做一次只读检查，记录当前项目/Alias、采集与队列状态；不擅自增加定时检查或改动队列/设置。只报告变化、异常及用户要求的进度。
- [ ] 用户问“还要多久”时，简报当前实际步骤、合理预计耗时及具体阻碍；不把页面预计剩余积分当成交接任务的完成时间。

## 4. 截止前与停止

- [ ] 提前恢复浏览器、检查两站会话、取得 OIC 证据并将 Observing 的当前 Alias/ID 与 Abort 控件置于可操作状态。恢复可能耗时；必要时建议比原准备点再早几分钟，获准后调整**准备**，不移动硬性 Abort 时间。
- [ ] 临近执行重新核实实时项目与当前 Alias（严格区分 `_R`），不能拿历史 Scheduling Block 作为当前源。确认未由下一项目接手、无保护阻止；若等待或页面恢复造成延迟，必须再读当前状态。
- [ ] 仅在本次授权操作窗和约定节点控制。过期唤醒或恢复后已超出授权窗，不补点 Abort/Start、不凭历史状态接管；报告未执行及当前可读状态。审批拒绝即报告，未确认停止不声称完成。
- [ ] 到批准时间 Abort 一次，等待过渡并确认本次 Block 结束、队列停止及望远镜实际状态；不额外 Park/Stow。**先确认停止并截取 Observing 画面，再注销 OIC 或交接。**

## 5. 释放责任与收尾

- [ ] 确认停止且本次授权包含注销后，打开 **jPORTAL → Observing → OIC → deRegister**；执行前再确认 OIC 仍属本人，执行后核实本人已注销。若已由下一人接管，不注销对方；若注销失败，报告残留责任，不声称交接完成。
- [ ] 核实停止和 OIC 释放状态后发送约定交接消息并确认显示。关页前逐页核对，仅关闭本次两个标签，不关其他页面或整个浏览器；未完成的故障现场保留。
- [ ] 给用户停止截图、实际停止时间（可得时）、队列/望远镜状态、OIC 与消息结果。将**计划积分、界面估计、日志实证的 scan/实际采集、截止时截断**分开表述；证据不足不推算“全部积分完成”。截图与运行细节只交付到获准位置，不提交公开仓库。
